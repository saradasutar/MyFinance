MYFINANCE BULK IMPORT UPGRADE

This upgrade adds a Bulk import button under Holdings.
It accepts CSV files with up to 500 investment rows.

STEP 1 — GOOGLE APPS SCRIPT
1. Open your existing Apps Script project.
2. Replace the complete Code.gs with google-apps-script/Code.gs from this package.
3. Click Deploy > Manage deployments.
4. Edit the current deployment.
5. Under Version, choose New version.
6. Click Deploy. Keep the same /exec URL.

STEP 2 — GITHUB
Upload these files to the root of the MyFinance repository and replace the old versions:
- github-frontend/index.html
- github-frontend/app.js
- github-frontend/styles.css

Do not replace your working config.js because it contains your Apps Script /exec URL.

STEP 3 — IMPORT
1. Sign in to the dashboard.
2. Open Holdings.
3. Click Bulk import.
4. Download the CSV template.
5. Put one asset per row, using total units and total invested amount.
6. Save as CSV UTF-8.
7. Select the CSV and click Import investments.

IMPORTANT
- Asset Type must be STOCK, ETF, MF or OTHER.
- Stock/ETF Code is the ticker, for example RELIANCE or GOLDBEES.
- Stock/ETF Exchange is normally NSE or BOM.
- MF Code is the numeric AMFI scheme code; Exchange stays blank.
- Purchase Date can be YYYY-MM-DD or DD/MM/YYYY.
- Manual Price is optional. Leave it blank for automatic stock/ETF price or MF NAV.
- Import adds new rows. Uploading the same file twice will create duplicates.
