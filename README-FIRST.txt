MYFINANCE V13 — SHOW ALL INVESTMENTS

NEW
A prominent “▦ Show All Investments” button is now in the Holdings toolbar.

ONE CLICK DOES ALL OF THIS
- Investor -> Combined
- Investment Type -> All Investments
- Holdings Type -> All assets
- Search box -> cleared
- Re-renders Holdings immediately
- Shows how many investments are currently loaded

INSTALL
1. Upload app-v13.js to GitHub as a NEW file.
2. Replace index.html.
3. Replace styles.css.
4. Keep config.js unchanged.
5. Do not redeploy Apps Script.
6. Commit and wait about one minute.
7. Confirm this opens JavaScript:
   https://saradasutar.github.io/MyFinance/app-v13.js
8. Open:
   https://saradasutar.github.io/MyFinance/?v=2000
9. Mac: Command + Shift + R.
