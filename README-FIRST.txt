MYFINANCE V17.2 — PERSONAL HOME + LARGER FONTS + ALTERNATE COLOURS

1) DEFAULT DASHBOARD IS NOW “MY HOME”
Investment details are hidden from the default Overview.

My Home shows:
- Today’s Diary preview
- Quick Daily Diary
- Quick Monthly Diary
- Active Targets & Reminders
- Due Today / Overdue / Upcoming counts
- Current target/reminder preview
- Quote of the Day

Investment details appear only when you choose:
- ₹ Investments at the top of Overview
- Holdings in the left menu
- Watchlist in the left menu
- ₹ View investments at the bottom of My Home

2) YOU CAN CHOOSE YOUR DEFAULT
Use:
✓ Default view / ☆ Make default

You can make either:
- My Home
- Investments
your normal Overview opening screen.

The choice is remembered in that browser.

3) LARGER FONTS
Fonts are increased throughout for easier viewing:
- Sidebar
- Buttons and filters
- Tables
- Holdings / Watchlist
- Full-screen tables
- Diary
- Right Notes & Quotes panel
- Overview information

Spacing remains compact so the dashboard does not become unnecessarily tall again.

4) ALTERNATE COLOURS
Soft alternate colours are added for easier visual separation:
- Personal Home cards
- KPI cards
- investment information panels
- Holdings / Watchlist table rows
- Diary / Monthly Diary items
- Target/reminder summaries
- other major information blocks

Colours remain light and eye-soothing to preserve readability.

5) QUOTE TEXT CHANGES COLOUR
Quote of the Day now rotates through six readable colour themes:
- Purple
- Blue
- Green
- Amber
- Rose
- Teal

The quote text, quote mark and background theme change together when the quote changes.
The same colour theme is used in My Home and in the right-side Quote panel.

6) EXISTING FEATURES RETAINED
- Holdings Full Screen
- Watchlist Full Screen
- Filters / Print
- Right Notes & Quotes panel
- Sticky Done → Daily Diary
- Quote Library + auto shuffle
- Quick Diary
- Notes Centre
- Horizontal scrolling
- Previous freeze/save fixes

BACKEND
Backend remains v3.8.0.
NO Apps Script redeployment required.
