MYFINANCE V17.3 — PORTFOLIO DETAILS ONLY AFTER OPENING HOLDINGS

WHAT CHANGED

OVERVIEW
- Overview is now only your personal Home.
- No portfolio selector appears in Overview.
- No Investment Type selector appears in Overview.
- No investment summary/cards/charts appear in Overview.
- The old Investments mode button is removed from the visible Overview.
- Overview remains focused on:
  Diary
  Targets / Reminders
  Quote of the Day

HOLDINGS
- The Portfolio selector appears only when Holdings is opened.
- The Investment Type selector appears only when Holdings is opened.
- + Add investment appears only in Holdings.
- “PORTFOLIO DETAILS · Mutual funds, stocks & ETFs” is kept on ONE LINE.
- The Holdings toolbar is placed beneath the title instead of squeezing the title into a narrow column.
- Full Screen remains available.

WATCHLIST
- Watchlist continues to use its own Search / Type / Priority / Target filters.
- The global Holdings portfolio selector is not shown there.

INVESTMENT ACCESS
To see investment information:
- Click Holdings
or
- Click Watchlist

The My Home footer button now says:
“Open Holdings”

BACKEND
Backend remains v3.8.0.
No Apps Script redeployment is required.
