MYFINANCE VIBRANT DASHBOARD — IMPORTANT

Upload these FOUR files to the ROOT of the GitHub repository:
1. index.html
2. styles.css
3. app.js
4. config.js

Do not upload only index.html.
Do not put the files inside another folder.
Do not upload the ZIP itself.

Before upload, open config.js and replace:
PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE
with your Google Apps Script Web App URL ending in /exec.

GitHub steps:
1. Open https://github.com/saradasutar/MyFinance
2. Add file > Upload files
3. Drag all four files into the upload area
4. Choose "Commit directly to the main branch"
5. Click Commit changes
6. Wait 1–3 minutes
7. Open https://saradasutar.github.io/MyFinance/
8. On Mac press Command + Shift + R

The files must appear at these exact repository paths:
/MyFinance/index.html
/MyFinance/styles.css
/MyFinance/app.js
/MyFinance/config.js
